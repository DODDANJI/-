# AGORA 제7호 메인 에디토리얼

빌드 없이 바로 열리는 정적 사이트예요. `index.html`을 브라우저로 열면 돼요.
이미지가 스크롤로 나타나는 효과를 보려면 로컬 서버로 여는 편이 안전해요 (예: 이 폴더에서 `python3 -m http.server` 실행 후 http://localhost:8000).

## 폴더 구성

| 파일 | 고치는 내용 |
| --- | --- |
| `index.html` | 모든 문구와 이미지 경로. 섹션마다 `<!-- 섹션 이름 -->` 주석이 있어요. |
| `css/style.css` | 색, 서체, 크기, 배치. 맨 위 `:root`의 값부터 바꿔 보세요. |
| `js/main.js` | 픽셀 효과, 타임코드, 썸네일 hover. 맨 위 `REVEAL` 값으로 효과를 조절해요. |
| `img/` | 이미지 파일. 모두 임시 이미지라 실제 화보로 바꿔 넣으면 돼요. |

## 문구 고치기

`index.html`에서 바꾸고 싶은 문장을 찾아 그대로 고치면 돼요. 섹션 순서는 아래와 같아요.

1. `full-bleed cover`: 커버. 헤더 메뉴, 커버 스토리 소개, 세로 한글 제목, `SOFT / ARCHITECTURE` 헤드라인, 하단 필름 스트립 네 장면
2. `opening`: 커버 아래 리드 문단과 크레딧(사진, 스타일링, 글, 장소)
3. `installation view`: 전시 전경 사진과 작품 캡션
4. `essay`: 인용문, 니트 사진, 에세이 본문, 주석
5. `exhibition`: 전시 정보(기간, 장소, 관람, 입장, 출품)와 룩 사진
6. `contents`: 이번 호 목차 이미지 그리드
7. 푸터: 다음 장 링크와 발행 정보

캡션은 `<b>` 안이 굵은 제목이고, 그 아래 `<span>`들이 회색 줄이에요. 협업 표시는 `<span class="x">✕</span>`를 쓰면 돼요.

## 이미지 바꾸기

`img/` 폴더에 같은 이름으로 덮어쓰거나, `index.html`의 `src="img/…"` 경로를 바꾸세요. 이미지 비율은 CSS가 맞춰 잘라 줘요.
`data-reveal`이 붙은 이미지에만 픽셀 효과가 적용돼요. 빼고 싶으면 그 속성만 지우면 돼요.

## 자주 바꾸는 값

- 색: `css/style.css`의 `--paper`(바탕), `--ink`(글자), `--mute`(회색 글자), `--cobalt`(강조색)
- 서체: `--display`(헤드라인), `--serif`(본문), `--util`(캡션과 메뉴). 서체를 바꾸면 `index.html` 맨 위 Google Fonts 링크도 같이 바꿔 주세요.
- 픽셀 효과: `js/main.js`의 `REVEAL.cell`(칸 크기), `band`(띠 두께), `duration`(속도), `color`(칸 색)
